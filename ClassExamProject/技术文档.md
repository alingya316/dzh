# TypeGame 技术文档

## 一、项目概述

TypeGame 是一个基于 Qt 的英文打字游戏合集，包含「拯救苹果 (SaveApple)」和「太空大战 (SpaceBattle)」两个游戏，以单一可执行文件 `typegame.exe` 统一交付。

### 技术栈

| 项 | 值 |
|---|-----|
| 语言 | C++17 |
| 框架 | Qt 5/6（Widgets + Multimedia + Network） |
| 构建系统 | CMake 3.16+，Visual Studio 2019+ |
| 测试框架 | GoogleTest 1.14 |
| 包管理 | vcpkg（Qt、GTest） |
| 平台 | Windows（Qt 接口跨平台可移植） |

### 产物

| 文件 | 说明 |
|------|------|
| `build/bin/Release/typegame.exe` | 主程序 |
| `build/bin/Release/spacebattle_tests.exe` | 太空大战 13 个单测 |
| `build/bin/Release/saveapple_nonui_tests.exe` | 拯救苹果 9 个单测 |

### 2.2 MVC 架构

两个游戏均使用 Model-View-Controller 模式：

```
用户输入 → View (QWidget/QGraphicsView)
              ↓ signal
         Controller (QObject + QTimer)
              ↓ 读写
         Model (纯数据结构)
              ↓ notify
         View → update() 重绘
```

**SpaceBattle MVC 数据流：**

```
键盘 A-Z → SpaceView::keyPressEvent → letterPressed(QChar)
         → SpaceController::onLetterPressed
            → 查找匹配敌机 → 创建追踪弹 → SpaceAudio::play(Shoot)
            → tick() 循环: 更新飞船/敌机/子弹/奖励词
            → SpaceModel 数据变化
            → SpaceView::refreshUi() → rebuildGameScene()
```

**SaveApple MVC 数据流：**

```
键盘 A-Z → GameView::keyPressEvent → letterPressed(QChar)
         → GameController::onLetterPressed
            → 查找匹配水果 → 标记命中 → AppleAudio::play(AppleIn)
            → updateGame() 循环: 移动水果、碰撞检测
            → GameData 数据变化 → IObserver::onModelChanged()
            → GameView::update() 重绘
```

### 2.3 统一入口路由

```
typegame.exe
├── 无参数 → GUI 启动器（GameLauncher）
│              ├── 点击"拯救苹果" → runAppleGui()
│              └── 点击"太空大战" → runSpaceGui()
├── apple  → 直接启动拯救苹果（跳过启动器）

├── apple --test --input cfg.json --output res.json → CLI 苹果测试

```

## 三、关键模块详解

### 3.1 SpaceBattle 游戏逻辑

**敌机系统：**
- 每 900ms（基础值，随难度缩短）生成敌机，1/4 概率为陨石
- 飞机：正弦波左右摆动下落，落底扣 1 HP
- 陨石：直线下落，撞飞机触发双方爆炸（不扣血），落底不扣血
- 字母分配：`nextUniqueLetter()` 保证场上 A-Z 字母唯一

**追踪弹系统：**
- 按字母键发射追踪弹，锁定最靠下的匹配敌机
- 同一敌机只允许一发在途子弹（防连按刷分）
- 子弹以 520px/s 飞行，转向率 8.0，命中半径 52px

**难度曲线：**
- 每 `upgradeIntervalSec` 升级：敌机数上限 +1（最高 10）、速度档 +1（最高 10）、间隔缩短 40ms（最低 250ms）

**奖励模式：**
- 英文单词从屏幕左侧飞过，玩家顺序键入正确后回满生命
- 单词由 LLM API（OpenAI 兼容）或本地 500 词汇表提供
- 配置：`llm_config.json` 或环境变量

### 3.2 SaveApple 游戏逻辑

**水果系统：**
- 每 900ms 在屏幕顶部随机 X 生成水果
- 每帧按速度下落，`GameData::update()` 驱动
- 水果类型权重：好苹果 60%、小苹果 25%、坏苹果 15%
- 坏苹果落底扣命，好苹果/小苹果落底丢失

**命中判定：**
- 按下字母键，优先匹配 Y 坐标最小（最靠下）的同字母水果
- 命中播放消失动画，得分+1

**过关系统：**
- `targetCount` 达到后触发过关界面
- `fallSpeed`（1-10）、`maxAppleCount`（1-5）可配

### 3.3 按钮系统（ButtonIconManager）

```
精灵图: [normal | hover | pressed] 横向三等分

ButtonIconManager::create(parent, path, size, mgr)
    ↓
registerButton()  → 裁切三态图标
    ↓
installEventFilter(mgr) → Enter/Leave/Press/Release 自动切换图标
    ↓
setAudioCallback() → Enter 触发悬停音效，Release 触发点击音效
```

两个游戏的按钮都通过此机制统一管理，零额外 eventFilter 代码。

### 3.4 游戏窗口生命周期

```
启动器点击
  ↓
runXxxGui() → 创建 MVC → setWindowTitle + setFixedSize
  ↓
setupGameWindow(view, &View::exitClicked, cleanup)
  ├── disconnect 原始 quit 信号
  ├── connect exitClicked → cleanup
  ├── installEventFilter(CloseFilter) → X 按钮 → e->ignore() + cleanup
  └── setWindowModality(ApplicationModal)
  ↓
view->show()
  ↓
用户点击退出 / X 按钮
  ↓
cleanup(): view->hide() → ctrl->onEnd/onReturn→ cleanup → deleteLater
  ↓
启动器恢复可用
```

## 四、性能优化

### 4.1 SpaceBattle 场景渲染

**问题**：每帧 rebuildGameScene() 删除全部 QGraphicsItem 再重建，60FPS 下每秒 ~1800 次堆分配。  
**方案**：拆分为静态层（m_staticGroup：背景、星空、HUD，创建一次）+ 动态层（m_dynamicGroup：飞船、敌人、子弹、奖励词，每帧重建）。  
**效果**：HUD 数值（分数、时间、生命条）通过成员指针就地更新，静态层 0 开销。

### 4.2 音频系统重写

**问题**：SaveApple 原 AudioManager（~600 行）使用工作线程 + 互斥锁 + 条件变量 + 事件队列。stopBgm() 通过 invokeMethod 异步投递，退出时音效残留。  
**方案**：改为惰性单例 AppleAudio（~70 行），继承 AudioBase。stopBgm() 先 setMuted(true) 再 stop()，同步静音。  
**效果**：消除竞态条件，代码减少 500+ 行。

### 4.3 启动性能

- typegame.exe 仅链接 QtWidgets + QtCore，不加载游戏资源
- 启动器资源：APPLE.PNG + SPACE.png（~5MB 总大小，QRC 编译时嵌入）
- 游戏资源在各自的 .lib 中，运行时由 QRC 系统按需加载

## 十、游戏交互设计

### 9.1 LLM API 配置（奖励词功能）

太空大战的奖励模式需要 LLM API 生成英文单词。配置文件优先级：

1. **`llm_config.json`**（放在 exe 同目录，从 `llm_config.example.json` 复制后填写 API Key）
2. **环境变量**

**配置文件格式：**

```json
{
    "apiUrl": "https://api.openai.com/v1/chat/completions",
    "apiKey": "sk-xxxxxxxxxxxxxxxx",
    "model": "gpt-4o-mini"
}
```

**环境变量：**

| 变量 | 说明 |
|------|------|
| `SPACE_LLM_API_URL` | API 端点 URL |
| `SPACE_LLM_API_KEY` | API Key |
| `SPACE_LLM_MODEL` | 模型名称 |
| `DASHSCOPE_API_KEY` | 阿里云百炼 Key（与 Go 示例一致） |
| `DASHSCOPE_COMPATIBLE_URL` | 百炼兼容端点（默认：`dashscope.aliyuncs.com/compatible-mode/v1/chat/completions`） |
| `DASHSCOPE_MODEL` | 百炼模型（默认：`qwen-plus`） |

## 十二、已知问题与改进方向

| 问题 | 影响 | 改进建议 |
|------|------|---------|
| 单测未覆盖 Controller/View/Audio | 覆盖率不足 80% | 引入 QTest 框架或 mock |
| CLI 测试结果不可复现 | 随机种子不一致 | 加 `--seed` 参数固定 RNG |
| 文件名大小写不统一 | 不符合 readme 规范 | 全改为小写+下划线 |
| SaveApple GameConfig 用 __FILE__ | 换机器编译路径失效 | 改用 QRC 或相对路径 |
| SpaceView 仍偏重（737 行） | 维护困难 | 拆分设置面板/高分面板 |
| 多分辨率未逐项验证 | 必过项未确认 | 1366×768 / 1920×1080 / 2K / 4K 实测 |
| 冷启动 < 200ms 未验证 | 验收风险 | 加 QElapsedTimer 埋点 |
| 未在 macOS/Linux 编译 | 跨平台未验证 | CI 接入 |
