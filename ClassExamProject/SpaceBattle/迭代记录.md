## 迭代 9 — 2026-05-03

### 问题
34. **每帧重建整个场景** — `rebuildGameScene()` 每帧 delete 全部子项再 new，60FPS 下每秒 ~1800 次堆分配
35. **SpaceModel::reset() 破坏用户设置** — `m_settings = SpaceSettings{}` 把自定义参数也重置了，依赖 Controller 事后恢复
36. **26 个布局常量未使用** — SaveApple 面板比例常量（1920×1080 参照）与实际使用的 1704×1278 坐标不一致，纯死代码
37. **碰撞检测魔法数字** — 飞船碰撞和陨石-敌机碰撞用硬编码 `100`，已有 `kShipSize`/`kEnemySize`/`kHitRadius` 却不用
38. **敌机 ID 用 static 局部变量** — `nextEnemyId()` 的 `s_id` 跨局不重置
39. **高分配存失败静默忽略** — `space.hi` 写入失败无任何日志
40. **`setShipAnimFrame` 双重取模** — `((f % 11) + 11) % 11` 多余
41. **`m_gameOverLabel` 可见性条件冗余** — `isEnd && inMenu` 中 `inMenu` 已覆盖 `End`
42. **图标刷新逻辑重复 3 处** — `resizeBtn` lambda、`setBtn` lambda、hiscore 返回按钮各自实现相同图标重建

### 修改
34. 场景拆分为静态/动态两层：`m_staticGroup`（背景、星空、HUD 标签、生命条、分数/时间文本）在进入 Playing 时创建一次并持久化，`m_dynamicGroup`（飞船、敌人、子弹、奖励词）每帧重建。HUD 数值（分数、时间、生命填充）通过成员指针 `m_sceneScoreText`/`m_sceneTimeText`/`m_sceneLifeFill` 就地更新
35. `SpaceModel::reset()` 移除 `m_settings = SpaceSettings{}`；settings 由 Controller 的 `m_baseSettings` 管理
36. 删除 26 个未使用的 `kSetting*` / `kSet*` 布局常量
37. 添加命名常量 `kShipCollisionHalf = 50.0` / `kMeteorAircraftCollisionHalf = 50.0`，替换两处硬编码 100
38. `nextEnemyId()` 改用成员变量 `m_nextEnemyId`，`resetGame()` 中重置为 1
39. `saveScore()` 写入失败时 `qWarning()` 输出文件路径
40. `setShipAnimFrame` 简化为 `(f % 11 + 11) % 11`
41. `m_gameOverLabel->setVisible(isEnd)` 去掉冗余 `&& inMenu`
42. 提取 `refreshButtonIcons(QPushButton*, QSize)` 辅助方法，三处调用统一
43. 修正 `m_btnHiscoreBack->setFixedSize()` 重复调用
