# ClassExamProject 类与函数说明

> 依据各模块 **头文件** 与核心实现整理，便于口试/维护查阅。  
> **未在头文件声明**的 `.cpp` 内**静态/匿名命名空间**工具函数见文末。

---

## 一、`typegame`（统一入口与启动器）

### `main`（`typegame/main.cpp`）

| 函数 | 作用 |
|------|------|
| `main` | 解析命令行；无参则显示 `GameLauncher` 并 `exec`；`apple`/`space` 可直开对应 GUI；`--test --input --output` 走 CLI 测试。 |

### `GameLauncher`（`typegame/GameLauncher.h` / `.cpp`）

| 函数 | 作用 |
|------|------|
| `GameLauncher(parent)` | 定窗口大小、加载两张卡片图标、启动 16ms 悬停插值定时器、布局卡片。 |
| `paintEvent` | 自绘背景、标题、两卡片、光晕、文案。 |
| `mouseMoveEvent` / `mousePressEvent` / `leaveEvent` | 更新悬停索引、点击卡片时 `launchGame(index)`。 |
| `resizeEvent` | 调用 `layoutCards`。 |
| `layoutCards` | 按参考分辨率比例计算两卡片 `QRectF`。 |
| `launchGame` | 发信号 `gameSelected(index)`（由 `main` 里连接 `runAppleGui` / `runSpaceGui`）。 |

**信号**：`gameSelected(int index)` — 0=SaveApple，1=SpaceBattle。

### `gui_mode`（`typegame/gui_mode.h` / `.cpp`）

| 函数 | 作用 |
|------|------|
| `runAppleGui` | 创建 `GameData` + `GameView` + `GameController`，设窗口与 `setupGameWindow`，`show`。 |
| `runSpaceGui` | 创建 `SpaceModel` + `SpaceView` + `SpaceController`，设 4:3 尺寸与 `setupGameWindow`，`show`。 |

### `cli_mode`（`typegame/cli_mode.h` / `.cpp`）

| 函数 | 作用 |
|------|------|
| `runSpaceCliTest` | 无头驱动太空大战，读 JSON 配置、跑多轮、写结果 JSON。 |
| `runAppleCliTest` | 无头驱动拯救苹果，写结果 JSON。 |

### `SpaceTestDriver`（`typegame/SpaceTestDriver.h`）

| 函数 | 作用 |
|------|------|
| `loadConfig` | 从 JSON 读 `CliTestConfig`（字母、设置、轮次等）。 |
| `run` | 构造 Model/View/Controller，按配置跑多轮模拟按键，返回结果 `QJsonObject`。 |
| `saveResult` | 将 JSON 写入文件。 |

### `AppleTestDriver`（`typegame/AppleTestDriver.h`）

| 函数 | 作用 |
|------|------|
| `run` | 按字母序列与时长驱动 SaveApple，返回 JSON。 |
| `saveResult` | 写文件。 |
